# OCR Workflow

## Purpose
Process invoices through OCR and AI.

---

## Steps

1. **Upload** – file received
2. **Pre-process** – convert to image if PDF
3. **OCR** – extract text
4. **AI Extraction** – identify fields
5. **Confidence Scoring** – assign scores
6. **Review** – flag low-confidence fields
7. **Save** – store extracted data
