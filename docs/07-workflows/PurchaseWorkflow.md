# Purchase Workflow

## Purpose
End-to-end workflow for processing purchase invoices.

---

## Steps

1. **Upload** – drag-and-drop or file picker
2. **OCR Processing** – system extracts data
3. **Review** – user reviews extracted fields
4. **Correct** – user fixes any errors
5. **Approve** – mark as approved
6. **Link to Period** – assign to tax period
7. **Include in Input Tax Statement**[reference:67]
