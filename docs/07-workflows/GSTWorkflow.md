# GST Workflow

## Purpose
End‑to‑end workflow for preparing a GST return.

## Steps
1. **Open Period** – user selects a new period.
2. **Import Purchases** – upload invoices; OCR extracts data; user reviews.
3. **Import Sales** – manual entry or import POS CSV.
4. **Review & Adjust** – apply credit notes, corrections.
5. **Generate Statements** – system calculates totals.
6. **Export** – download MIRA 205 Excel.
7. **Submit** – user submits to MIRA manually, marks as "filed".
