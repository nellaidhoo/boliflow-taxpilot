# Product Goals

## Purpose
Define measurable objectives for the MVP and subsequent releases.

---

## MVP Goals (v1.0)

- Allow a business to register and set up their GST profile.
- Upload purchase invoices (PDF, image) via drag‑and‑drop.
- Extract key fields (supplier, invoice number, date, total, GST amount) using OCR/AI.
- Manually enter sales or import from POS CSV.
- Automatically generate Input Tax Statement and Output Tax Statement.
- Export GST return (MIRA 205) as Excel/PDF.
- Provide a simple dashboard with tax liability summary.

## v2.0 Goals

- Income Tax preparation (MIRA 604) – auto‑calculate taxable profit from expenses and sales.
- Supplier knowledge base – auto‑recognise recurring suppliers.
- Multi‑business support under one account.
- Accountant collaboration (invite, review, submit).

## v3.0 Goals

- e‑Invoicing integration with MIRA.
- Bank feed integration (auto‑import transactions).
- AI‑powered anomaly detection.
- Mobile app for invoice capture.

## Key Metrics

- Time to prepare GST return: from hours → <5 minutes.
- Manual data entry reduction: >90%.
- Accuracy: 99%+ on extracted fields.
- User adoption: 100 businesses in first 6 months.
